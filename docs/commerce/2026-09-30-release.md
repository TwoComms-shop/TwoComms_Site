## Состав

Скидки225 от любых двух изделий, server full-payment policy для всех бригад, предложения на карточках/PDP/корзине наuk/ru/en. Исторические оплаченные заказы не меняются. Лонгсливы, черновики и архивы не меняются.

## Проверки до выпуска

-128 целевых тестов прошли на изолированной копии чистого HEAD с файлами только этого изменения. Runtime CPython3.14.6/Django6.1, SQLite. Дополнительно20тестов финального guardedpricecommand у автора и независимыйreview.
-Широкий запуск115тестов выявил два существующих сбоя: lazytranslation custom_print_safe_exit JSON и ожидание русского заголовка «Посадка» при фактическом «Тип посадки». Оба воспроизведены на исходном коде HEAD в отдельной копии; не относятся к этому выпуску. Игнорируемый backupшаблон в рабочем checkout не включён в выпуск.
-Реальный браузер local: UKmobile390 без горизонтальногоoverflow; RUdesktop1440; ENcopy/PDP/cart. Переключение225classic880→oversize1030; mixedset2650; удалениеteeвозвращаетhoodie1995; увеличениеhoodieдо2даёт3700 и290экономии. Предоплата отключена с видимым объяснением натрёх языках. Реальные заказы/инвойсы приUIпроверке не создавались.
-Политика server проверена для forgedpartialrequest, смешаннойкорзины, promoexclusion, frozeninvoiceamounts, Instagramlegacy/v2 unpaidlinks. Оплаченнаяисториясохраняется.
-EventsManager/CommerceManager прочитаны авторизованно; PurchaseactiveEMQ8/10, matching97,5%, ATC/Purchase100%. DedupUI ещёанализируетданные, поэтому100%dedupнеутверждается. Подробности и ограничения в advertising-audit.
