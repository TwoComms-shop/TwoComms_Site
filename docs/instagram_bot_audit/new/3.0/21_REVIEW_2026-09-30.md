Ни private code, ни клиентские данные в документацию не отправлялись.

- [Gemini3.8 Flash](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash): exact model ID, multimodal inputs, text output, structured output, low/medium/high thinking; minimal недопустим. Public limits не доказывают access/capacity конкретных проектов.
- [Rate limits](https://ai.google.dev/gemini-api/docs/rate-limits): quota per project, RPD reset Pacific midnight, active limits зависят от model/tier. Отсюда plan gate project identity/DST/unknown, не «Free Tier безлимитный».
- [Thinking](https://ai.google.dev/gemini-api/docs/thinking), [structured output](https://ai.google.dev/gemini-api/docs/structured-output), [tokens](https://ai.google.dev/gemini-api/docs/tokens): endpoint/model-specific configuration, bounded token allocation и application semantic validation; byte estimate для multimodal не exact tokenizer. Новые examples не разрешают скрытую migration generateContent→Interactions.
- [Requests timeouts](https://requests.readthedocs.io/en/latest/user/quickstart/#timeouts): connect/read inactivity timeout не total wall deadline. Отсюда late-result/boundary tests, а не обещание hard deadline по сумме tuple.

Meta native recurring/repost capability конкретного account здесь не проверена: это явный activation gate P4-3/P2-5, не обещание доступного API. Actual Gemini generation quality/access тоже не проверялись synthetic calls.
