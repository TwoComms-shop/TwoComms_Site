# P2-5 · Media interpretation and service reaction core · 07.10.2026

## Scope and contract

One existing live request produces bounded, typed per-part interpretations for images, audio and supported video. Every interpreted part is bound to the actual submitted prefix, content hash, current USER source, request and winning provider attempt. Omitted, unreadable and unavailable parts remain separate limitations; historical unknown media is not upgraded to an inspection.

The canonical producer, immutable generation proposal, existing attachment inspection projection, response policy and manager-case consumer use the same proof. Projection records only inspection and preserves original input media/provenance. Commerce source fences ignore the recognized backend inspection owner, retain explicit input identity, and accept old raw fences only on an exact unchanged match.

Service takes priority over positive-media praise. A meaningful current caption survives native-UGC acknowledgement and unavailable media; caption-derived service tone does not invent a media complaint or authorize an action. Bare native UGC suppresses catalog controls and unsolicited selection. Explicit current commerce remains subject to existing source, cart and semantic coverage guards. A sent counterquestion does not complete an unanswered question or purchase.

Verified media complaints create an exact revision-scoped manager case and one queued notification. Separate complaint revisions are not merged into an unrelated open case. Replay does not regenerate, duplicate a case or fabricate a delivered manager reply. Legacy current explicit manager/service requests survive UGC suppression; an unjustified model manager tag on a bare photo does not escalate.
